# FlowNexaX Agora Communication and Live Streaming Configuration Tutorial

## Disclaimer

FlowNexaX has no partnership or cooperation relationship with Agora.

FlowNexaX only integrates Agora's communication and live streaming features. This is similar to an app integrating WeChat login: it uses a third-party capability, but that does not mean there is a cooperation relationship.

The pricing of Agora communication and live streaming services is set by Agora itself and has nothing to do with FlowNexaX.

After you register an Agora account, Agora may provide free monthly usage, such as:

- 10,000 minutes of free live streaming per month
- Free communication for 1,000 devices per month

Please refer to Agora's official information for the exact and latest details.

The reference date for the information above is **2025-12-26**.

## Why Do You Need to Register an Agora Account Yourself?

First, FlowNexaX does not charge you any live streaming or communication fees.

FlowNexaX is a free product.

To ensure the stability of the cloud control feature, FlowNexaX needs to integrate with a mature third-party video live streaming and communication platform so it can provide better service.

However, because FlowNexaX is free to use, FlowNexaX cannot also pay the video live streaming and communication costs for users.

Agora is a mature third-party service provider, and it provides users with a free usage quota.

Normally, the 10,000 minutes of live streaming time provided after you register an Agora account should be enough for typical use. If you need longer usage time, Agora's pricing is also relatively inexpensive. You can check the specific prices on Agora's official website.

FlowNexaX currently integrates Agora's ultra-low-latency live streaming service, and the video quality used is the lowest-cost video HD option.

## 1. Register an Agora Account

Click to register:

[Agora.io Signup](https://www.agora.io/en/signup/)

## 2. Create a New Project After Registration

After registration is complete, create a new project.

You can enter any project name, choose any usage scenario, and select **Secure Mode**.

Then save and submit.

## 3. Open the Project Operations Page

After the project is created, click **Operate** or the corresponding operation entry for the project.

## 4. Copy the App ID and App Certificate

Copy the following two values from the Agora project page:

- App ID
- App Certificate

## 5. Fill the App ID and App Certificate into FlowNexaX

Open FlowNexaX and go to:

```text
Profile / Personal Center → Cloud Control Configuration
```

Fill in the Agora **App ID** and **App Certificate**.

After saving the configuration, FlowNexaX can use the related Agora communication and live streaming features for cloud control.
