# FlowNexaX ADB Mode: How to Fill in the Computer IP Address

This tutorial explains how to configure the computer IP address for FlowNexaX ADB running mode.

Telegram contact/link:

https://t.me/flownexax

## 1. ADB Mode on Rooted Phones

If your phone is already rooted, you can run ADB mode directly.

You do not need to install the computer-side software.

## 2. ADB Mode on Non-Rooted Phones

If your phone is not rooted, you can download the **FlowNexaX Win** software on a Windows computer.

Your phone and computer must be connected to the same Wi-Fi network.

Then fill in your computer's IP address in the FlowNexaX app:

```text
Profile / Personal Center → Basic Configuration → Running Mode
```

The **FlowNexaX Win** software can be downloaded from the FlowNexaX Telegram:

https://t.me/flownexax

After downloading and installing **FlowNexaX Win** on your computer, follow the tutorial inside the **FlowNexaX Win** software to connect your phone to it.

After the phone is connected to **FlowNexaX Win**, you can run ADB mode even if your phone is not rooted.

Please note that some features do not support ADB mode. For details about which features are unsupported, check the runtime log. The runtime log will show the related prompt.

## 3. How to Check Your Computer IP Address

First, make sure your phone and computer are connected to the same Wi-Fi network and are in the same local area network.

On your computer, press:

```text
Win + R
```

Then enter:

```text
cmd
```

In the command prompt, enter:

```text
ipconfig
```

Find the IPv4 address.

The address after `IPv4 Address`, such as:

```text
192.168.**.**
```

is your computer's IP address.

Fill this IP address into the FlowNexaX app:

```text
Profile / Personal Center → Basic Settings → Running Mode
```

Your computer must install the **FlowNexaX Win** software.
