# FlowNexaX

FlowNexaX is an app designed to make mobile phone usage more accessible and efficient for different groups of users.

FlowNexaX 是一款帮助不同用户群体更高效、更无障碍使用手机的 APP。

## App Introduction / 应用介绍

FlowNexaX helps people with disabilities use mobile phones more accessibly, helps automation testers improve testing efficiency, and helps office users improve productivity through office automation.

FlowNexaX APP 可帮助残疾人无障碍使用手机，帮助自动化测试人员提升测试效率，也能帮助普通办公人员通过办公自动化提升工作效率。
